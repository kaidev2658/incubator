## 모든 카드에서 병렬 에이전트를 실행하는 오픈소스 Kanban 데스크톱 앱

링크: https://news.hada.io/topic?id=29830

[핵심 요약]
KanBots는 칸반 카드마다 Claude Code와 Codex를 병렬 실행하고, 카드별 작업을 별도 git worktree로 격리해 진행 상황·비용·결정을 한 보드에서 추적하는 데스크톱 앱입니다. 폴더를 보드로 바로 가져오고 각 카드 실행 결과를 PR·브랜치 중심 흐름으로 연결하는 점이 특징입니다.

[기술적 인사이트]

## 80386 마이크로코드 역어셈블됨

링크: https://news.hada.io/topic?id=29829

[핵심 요약]
80386의 94,720비트 마이크로코드 ROM을 고해상도 다이 이미지에서 추출해 역어셈블한 사례입니다. 이미지 처리와 신경망 기반 보조 추출, 수작업 검증을 조합해 바이너리 블롭을 복원했고, x86 내부 동작을 더 구체적으로 해석할 수 있는 기반을 만들었습니다.

[기술적 인사이트]
반도체 리버스엔지니어링이 이제는 이미지 처리 자동화와 ML 보조 워크플로를 결합한 반자동 분석 단계로 넘어갔습니다. 폐쇄형 하드웨어도 시간이 지나면 해석 가능성이 높아진다는 뜻이라, 장기적으로는 칩 설계 보안과 지식재산 보호 전략도 더 정교해질 필요가 있습니다.

## AI는 아직 수익성이 있는가?

링크: https://news.hada.io/topic?id=29816

[핵심 요약]
프런티어 AI 기업들의 누적 지출과 매출을 합산하면 산업 전체는 아직 적자라는 분석입니다. 요약 기준으로 누적 지출은 약 1.4조 달러, 누적 매출은 약 6,130억 달러로 제시됐습니다.

[기술적 인사이트]
AI 도입이 활발하더라도 인프라 투자 회수 속도가 늦으면 시장은 성장보다 현금흐름을 다시 보기 시작합니다. 실무적으로는 모델 성능 경쟁만 볼 게 아니라, 추론 단가 절감과 고마진 워크플로 내재화가 실제 승부처라는 뜻입니다.


## microsoft/mimalloc - 고성능 범용 메모리 할당자

링크: https://news.hada.io/topic?id=29812

[핵심 요약]
mimalloc은 기존 프로그램에 큰 코드 수정 없이 적용 가능한 범용 메모리 할당자로 소개됐고, 일부 워크로드에서 jemalloc·tcmalloc 대비 속도와 메모리 사용 면에서 경쟁력을 보인다고 정리됐습니다.

[기술적 인사이트]
애플리케이션 성능 병목이 비즈니스 로직보다 allocator 특성에서 나오는 경우가 여전히 많다는 점을 상기시킵니다. 특히 AI 서빙, 데이터 처리, 고동시성 백엔드에서는 언어 런타임 밖의 시스템 레이어 튜닝이 비용 절감에 직접 연결될 수 있습니다.


## BambuStudio는 포크 이후 PrusaSlicer AGPL 라이선스를 위반해 왔다

링크: https://news.hada.io/topic?id=29814

[핵심 요약]
BambuStudio가 AGPL 기반 PrusaSlicer를 포크한 뒤 네트워크 플러그인 일부를 닫힌 바이너리로 유지해 라이선스 취지에 어긋난다는 비판이 제기됐습니다. 핵심 쟁점은 분리 배포된 바이너리가 실질적으로 필수 기능인지 여부입니다.
