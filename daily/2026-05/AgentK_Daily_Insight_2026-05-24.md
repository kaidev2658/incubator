## 항목 1. GitHub App 설치 토큰 형식 전환 대비
링크: https://news.hada.io/topic?id=29805

[핵심 요약]
GitHub이 GitHub App 설치 토큰 롤아웃을 위해 `X-GitHub-Stateless-S2S-Token` 임시 헤더를 도입했습니다. 새 토큰은 `ghs_` 접두사를 가진 JWT 형식으로 길이가 길고 점(.)을 포함하므로, 토큰 길이·정규식·DB 컬럼 크기·파서 전제를 점검해야 합니다.

[기술적 인사이트]
이번 변경은 인증 토큰 자체보다도 주변 인프라의 암묵적 가정을 깨는 유형입니다. 사내 게이트웨이, 비밀 저장소, 감사 로그 마스킹, 정규식 검증기, DB 스키마가 짧은 opaque token을 전제로 해 왔다면 배포 직전 장애가 날 수 있습니다. 운영팀 관점에서는 실제 전환 전에 헤더 기반 canary 테스트를 넣고, 토큰을 “구조 해석 없이 전달”하는 방향으로 경계 계층을 단순화하는 것이 맞습니다.

## 항목 2. Deno 2.8의 Node 호환성과 배포 도구 강화
링크: https://news.hada.io/topic?id=29799

[핵심 요약]
Deno 2.8은 접두사 없는 패키지명을 기본적으로 `npm:`으로 해석하고, `deno ci`, `deno pack`, `deno transpile`, `deno why`, `deno bump-version` 같은 서브커맨드를 추가했습니다. Node API 호환성도 자체 테스트 기준 76.4%까지 올라가고, npm 설치와 여러 런타임 경로 성능이 크게 개선됐습니다.

[기술적 인사이트]
포인트는 “새 런타임”이 아니라 “Node 프로젝트를 덜 아프게 데려오는 런타임”으로 이동하고 있다는 점입니다. 특히 패키지 설치 UX, 배포용 패키징, 의존성 추적, Node 타입 기본 해석까지 한 번에 보강하면서 Deno 채택 비용을 낮췄습니다. 다만 `setTimeout` 반환형이 숫자에서 `Timeout` 객체로 바뀌는 식의 호환성 변화는 기존 타입 선언과 테스트 코드에 은근한 회귀를 만들 수 있어, 일부 레거시 코드베이스는 기계적 업그레이드 전에 타입 검사가 먼저 필요합니다.

## 항목 3. DeepSeek V4 Pro 가격 인하의 상시화
링크: https://news.hada.io/topic?id=29797

[핵심 요약]
DeepSeek이 V4 Pro의 75% 할인 가격을 프로모션 종료 후에도 유지하기로 하면서, 입력 캐시 적중·미적중과 출력 토큰 단가가 기존의 1/4 수준으로 사실상 재기준화됐습니다. 1M 컨텍스트, 384K 최대 출력, Pro 동시성 500이라는 스펙이 이 가격대에 고정되는 점이 핵심입니다.

[기술적 인사이트]
이건 단순 가격 이벤트가 아니라 모델 라우팅 전략을 다시 짜게 만드는 신호입니다. 고성능 모델을 “예외적 비싼 경로”가 아니라 상시 선택지로 둘 수 있게 되면, 팀들은 요약/검색은 저가 모델, 복잡 추론과 장문 생성은 Pro 같은 이원화보다 캐시 활용과 요청 병렬성 중심으로 비용을 재설계하게 됩니다. 경쟁사 입장에선 품질보다도 장문 컨텍스트와 캐시 단가가 더 직접적인 압박 포인트가 됩니다.

## 항목 4. Project Glasswing가 보여준 AI 보안 운영의 병목 이동
링크: https://news.hada.io/topic?id=29790

[핵심 요약]
Anthropic의 Project Glasswing는 약 50개 파트너와 함께 중요 소프트웨어에서 1만 건 이상의 높음·치명적 취약점을 찾았고, 오픈소스 1,000개 이상을 스캔해 23,019개 취약점을 추정했다고 밝혔습니다. 발견 속도는 크게 빨라졌지만 실제 병목은 검증, 공개 조율, 패치 설계와 배포로 이동했다고 정리했습니다.

[기술적 인사이트]
보안팀의 핵심 과제가 “취약점이 부족한 상태”에서 “처리 파이프라인이 부족한 상태”로 옮겨가고 있습니다. 앞으로 경쟁력은 더 잘 찾는 모델보다도, triage 자동화, 재현 증거 표준화, 패치 우선순위화, 유지관리자 커뮤니케이션 속도에 달릴 가능성이 큽니다. 즉 AI 보안은 탐지 모델 자체보다 운영 체계와 릴리스 프로세스를 얼마나 빨리 돌릴 수 있느냐가 더 중요해지고 있습니다.
