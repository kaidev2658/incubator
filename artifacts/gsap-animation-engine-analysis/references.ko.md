## Source Use Note

이 보고서는 GSAP 개념과 runtime behavior에 대해 공식 GSAP 문서를 기준으로 한다. `requestAnimationFrame`, Web Animations API 같은 browser-native animation primitive는 MDN을 기준으로 정리했다. Tizen/EFL reference는 native feasibility mapping을 보강하기 위한 자료이며, 여기서 제안한 native 구현 구조는 기존 Tizen GSAP equivalent가 있다는 의미가 아니라 architectural mapping이다.
